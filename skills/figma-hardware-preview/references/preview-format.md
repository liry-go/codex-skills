# 按钮与预览包

静态预览只需要 `frame.png`。预览器将整个画面居中等比缩放，比例不同处留黑边。以导出 PNG 的实际像素为坐标系，左上角为原点。若 Frame 的设计尺寸与导出尺寸不同，分别换算设计矩形的四条边，核对组件、圆角和投影在导出图上的位置。

需要按钮反馈时，创建 UTF-8 的 `buttons.json`，其中每项覆盖一个完整的变化区域。用 Figma 指定状态或用户提供的素材在本地制作瓦片，按下与松开只改变这些区域。矩形必须在原图内、彼此不重叠，瓦片与矩形尺寸一致。打包器在 `buttons.json` 同目录查找瓦片。

```json
[
  {
    "label": "确认",
    "rect": [620, 322, 180, 68],
    "mode": "sink",
    "underlay": "confirm-underlay.png",
    "face": "confirm-face.png",
    "depth": 6,
    "press_ms": 70,
    "release_ms": 140
  },
  {
    "label": "关闭",
    "rect": [850, 40, 80, 48],
    "mode": "patch",
    "pressed": "close-pressed.png",
    "press_ms": 0,
    "release_ms": 0
  }
]
```

- `sink` 用于指定的下沉范式。底图包含区域内原有背景和固定的底部阴影；透明面片包含原按钮表面、文字和图标，位置与静态图一致。按下时面片下沉 `depth` 个导出像素，盖住原底座；松开后还原。把两个素材在原位置叠合，与静态裁片对照，检查背景连续及按下时四边完整。
- `patch` 用于已有的按下变体或可从可靠原始图层合成的变体。瓦片应包含整个区域在按下时的画面，包括露出的原背景。指定时长时进行渐变，否则立即切换。无需新增视觉元素。适用于只改变背景、描边或阴影的按钮。
- 优先使用指定时长和深度。仅当用户选用下沉范式且设计未给出时长时，可采用此前实机使用的 70ms 按下、140ms 恢复；深度按原按钮的阴影或设计变体换算。未指定范式时不推测点击区域。无法取得可信的面片、背景或状态时保留静态。

打包器会生成 ZIP。预览器支持 4096px 内的静态 PNG、最多 64 个按钮、最多 24 MiB 的预览包。按下、松开、触点移出和触摸取消均只影响视觉状态。实机比对时先看默认画面，再比对实际按下区域和复位画面。
